# موقع ترست سمارت — التصوّر الجديد

تصوّر تفاعلي كامل للصفحة الرئيسية، HTML/CSS/JS خالص بلا إطار عمل ولا حزم ولا أي طلب خارجي.

## التشغيل

ما فيه build. افتح `site.html` مباشرة، أو:

```bash
python3 -m http.server 8000   # ثم http://localhost:8000/site.html
```

الخطوط والصور والشعارات كلها محلية، فالصفحة تشتغل بلا إنترنت.

## البنية

```
site.html              الصفحة الرئيسية (كل الـCSS والـJS داخلها)
design-system.html     نظام التصميم: الألوان والخطوط والمسافات والمكوّنات
index.html             تحويلة إلى site.html (لـ GitHub Pages)
assets/
  tokens.css           مصدر الحقيقة: الألوان والخطوط والمسافات والحركة
  fonts/               المُرعي (Almarai) بأربعة أوزان — نفس خط البروفايل
  logos/               ١١٨ شعار عميل
  img/                 صور الأعمال والفعاليات والإنتاج والملمس
  brand/               شعار ترست (تراكوتا + كريمي)
```

## الأسلوب

مطبعي ورقي، امتداد لبروفايل ٢٠٢٦: ورق كريمي `#F3EFE0`، حبر إسبريسو `#2A1D14`، تراكوتا `#8A3D27`، وخط المُرعي.
مختلف عمداً عن موقع أهداف (بنفسجي داكن + شبكة نقاط)، لكن **بنفس أفكار الأقسام والتفاعل**.

| القسم | الآلية |
|---|---|
| البطل | ثلاث «أوراق» تتزحزح مع المؤشر + عنوان يصعد سطراً سطراً + شريط أرقام متحرك |
| الأرقام | عدّادات تبدأ من صفر عند دخول القسم |
| التحديات | سجل أسود، كل صف يُفتح بالضغط (واحد فقط في كل مرة) |
| منظومة النمو | أربعة ألواح، اللوح المفتوح يتمدّد والعنوان يستدير من عمودي لأفقي |
| الأعمال | معاينة صورة تتبع المؤشر فوق قائمة الحملات |
| المؤثرون | رقم كبير يعدّ + أشرطة نسب تنمو عند الظهور |
| الفعاليات | خط عمودي يُرسم مع التمرير والنقاط تتلوّن مرحلة بعد مرحلة |
| العملاء | ثلاثة صفوف شعارات متعاكسة الاتجاه |
| تواصل | نموذج ينتهي برسالة واتساب معبّأة |

## RTL واللغة

الموقع عربي أساساً مع زر `EN`. كل نص قابل للترجمة عليه `data-en`، والجافاسكربت يحفظ النسخة العربية في `data-ar` عند التحميل ويبدّل بينهما مع قلب `dir`.

**انتبه:** معاينة الأعمال (`#wprev`) تستخدم `left/top` الفيزيائية عمداً لأن `inset-inline-*` تنعكس في RTL وتكسر تتبّع المؤشر.

## المحتوى

الأرقام والنصوص والأعمال مسحوبة من بروفايل ترست سمارت ٢٠٢٦، والخدمات وبيانات التواصل من `trust-smart.co`.
كل النصوص أُعيدت صياغتها وترتيبها للويب: جمل أقصر، عناوين كلمة إلى كلمتين، وبلا كلمة «وكالة».

## ملاحظات مفتوحة

- **نموذج التواصل واجهة فقط.** يفتح واتساب برسالة جاهزة، ما يحفظ في قاعدة بيانات. يحتاج ربطاً بباك إند عند الإطلاق.
- **شعارات العملاء** معروضة كمرجع أعمال، تحتاج مراجعة إذن العرض قبل النشر الرسمي.
- **صور الأعمال** بعضها لقطات من فيديوهات بدقة منخفضة (٩٦٠×٥٤٠)، يفضّل استبدالها بالأصول الأصلية.
- ما فيه صفحات داخلية بعد: كل شي في صفحة واحدة طويلة.
